01 / The loop

A round, not a race

Six ticks, three actions, one pulse. Freeze the plate, aim drums and move lenses, then let it run. A six-tick trace makes the immediate future readable without making it safe.

First failure: a live board plus free clicking was a slot machine.
02 / The board

64 words, four planes

Each row is one 64-bit word. Eight shifted copies are added into four carry planes, so every cell's 0–8 neighbour count exists at once. Lens discs become region masks; the next state is composed by mask, not by branch.

Measured in the prototype: ~0.2 ms per 64 × 64 tick.
03 / The proof

Par is certified

A level is a seed, eight rings, three presets, a target and a budget. The page runs the same beam search and BFS replay as certify.mjs. Five plates ship with a verified witness and a par; the solver button re-derives a line in this tab.

Every shipped par is a replayed line, not a guess.
04 / The link

The link is a negative

A mid-bout plate is a snapshot: flags, seed, tick, budget, lens centres, drum rings, an RLE board and a checksum. RLE → deflate-raw → base64url. Raw would be 683 characters; a sparse plate lands near 200.

Versioned, checksummed, and restored into the exact same state.

01 / The case

Momentum, not obedience

The case runs itself. Care is rare: mist +5 disturbance, prune +8, stir +12. Above 60 the colony loses health; below 45 it recovers. Collapse is a slow decline, not one bad click. Restraint is the mechanic.

First failure: "over-intervention kills" with no visible bill was a punishment, not a rule.
02 / The organism

A program, not a screenshot

Genome, seed, age and care log replay to the exact plate. A genome is fixed for a specimen; editing it presses a new one. That keeps the history honest and the link short.

A 4,096-bit screenshot is 683 characters before compression. A program is usually under 90.
03 / The reading

Species are counted

Every connected component is run forward up to twelve generations. If its normalized shape returns, it is a still life, an oscillator or a ship; period and translation are recorded. Unique signatures give biodiversity. Cell colour is the classifier, not decoration.

The case is legible because the engine reads it, not because a legend says so.
04 / The fossil

No server, no expiry

Program mode is ~40–90 characters. Snapshot mode is RLE + deflate-raw, roughly 200–400. Both end in an FNV-1a checksum; the loader replays and compares. A mismatch is reported as fossil drift rather than silently showing a different creature.

The URL is the specimen. Opening it is the act of un-pressing it.
